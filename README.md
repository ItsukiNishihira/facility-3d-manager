# facility-3d-manager
業務改善アプリ

客室清掃3D（Facility 3D Manager）：建物外観（`reference/全体画像.png`）をもとにした3Dモデルで、2F〜5F・各階9室（計36室）の清掃状況を見える化する、ホテル清掃・ビルメンテナンス向けのツールです。

- スマホ・PCで開く：https://itsukinishihira.github.io/facility-3d-manager/
- アプリ本体は `index.html` 1ファイルです（`main` ブランチの内容がそのまま上のURLで公開されます）
- 入力した清掃状況・メモ・写真は Supabase（クラウド）に保存され、全端末にリアルタイムで共有されます。通信できないときは端末内（localStorage）に保存されます
- 画面右上に同期状態（クラウド同期済み／保存中／同期エラー）を表示します

## Supabase 初期設定
1. Supabase 管理画面 > SQL Editor に `supabase/setup.sql` の全文を貼り付けて実行（表・アクセス権・リアルタイム配信・写真保存先を作成）
2. アプリを開くと、36室分のデータが自動で作成されます（端末内に既存の記録があれば、それをクラウドへ移行）
