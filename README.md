# facility-3d-manager
業務改善アプリ

客室清掃3D（Facility 3D Manager）：建物外観（`reference/全体画像.png`）をもとにした3Dモデルで、2F〜5F・各階9室（計36室）の清掃状況を見える化する、ホテル清掃・ビルメンテナンス向けのツールです。

- スマホ・PCで開く：https://itsukinishihira.github.io/facility-3d-manager/
- アプリ本体は `index.html` 1ファイルです（`main` ブランチの内容がそのまま上のURLで公開されます）
- 入力した清掃状況・メモ・写真は、開いた端末のブラウザ内（localStorage）に保存されます。端末間では共有されません
